Delete All Data

Permanently delete all saved experiment outputs for E1–E6 and ground-truth annotations.

This will delete:
  • ✗Experiment run history (E1–E6)
  • ✗Extracted results and cached extractions
  • ✗Model outputs and raw responses
  • ✗Verdicts, reasons and confidence
  • ✗Ground-truth annotations (ground_truth.json)
This will NOT delete:
  • ✓Policies and policy versions
  • ✓API credentials
  • ✓Configuration settings
  • ✓System and application data
!
This action cannot be undone. A confirmation step with run count (0 saved runs) will be required before deletion.
Note:For audit and reproducibility, do not change configuration during an active evaluation cycle. Record any changes in the research log.
Page Guide

This page defines the technical configuration used by the research experiments. Use consistent settings to ensure valid and comparable results.

OpenRouter API Key

Authenticates requests to the model provider via OpenRouter. Your key is stored only in this browser (localStorage) and is not exported.

Vision Model (Layer 1)

Used for OCR and document understanding in Experiment E1. Different models may produce different extractions, affecting later experiments.

Reasoning Model (Layer 3)

Used for policy interpretation and verdict generation in Experiments E2–E6. Changes will impact how policies are evaluated and classified.

Currency Override

Determines the currency used in prompts and reasoning. "Any" preserves the currency detected on the receipt.

Save Settings

Stores the current configuration. All subsequent runs will record this configuration unless explicitly overridden.

Test Connection

Verifies connectivity to OpenRouter and confirms the selected models are available.
